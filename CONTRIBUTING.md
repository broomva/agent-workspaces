# Contributing

Corrections, accessibility improvements, translations and tooling fixes are
welcome through issues and pull requests:
https://github.com/broomva/agent-workspaces/issues

Explain the problem and the resulting behavior. Keep citations with factual
changes, and include the original source and license for third-party material.
Do not submit private workspace data, client material, credentials, or material
you do not have permission to contribute.

Run `bun run check`. For rendering or interaction changes, also run
`bun run smoke`; see README.md for browser prerequisites. Generated release
files are not edited by hand. Do not replace an existing published version.

Unless you explicitly state otherwise, contributions are made under the
existing license for the material being changed: Apache-2.0 for code and
CC BY 4.0 for authored prose. Fonts retain their own OFL terms. You retain
copyright in your contributions. See ATTRIBUTION.md and README.md for scope.
